# Odingram 🚀

Odingram — это легковесный и быстрый мини-мессенджер на Java, работающий по архитектуре Клиент-Сервер. Проект построен на стандартной библиотеке Java с использованием низкоуровневых сетевых сокетов (`java.net.Socket`) и многопоточности, что обеспечивает обмен сообщениями в реальном времени.

Интерфейс клиента реализован на классическом графическом фреймворке **JavaFX**.

## ✨ Основные возможности

* **Многопоточный сервер:** Одновременная обработка множества активных клиентов без зависаний.
* **Общий чат:** Публикация сообщений для всех участников, находящихся в сети.
* **Приватные сообщения:** Общение тет-а-тет с конкретным пользователем с помощью команды `/private`.
* **Автоматическое сохранение истории:** Все сообщения и системные события сохраняются в файл `chat_history.txt` на сервере и автоматически загружаются новым клиентам при входе.
* **Система команд:**
    * `/rename <новый_ник>` — мгновенное изменение никнейма в чате с проверкой на уникальность.
    * `/private ник сообщение` — отправить личное сообщение пользователю, будет видно только ему.
    * `/clear` — очистка истории чата.
    * `/help` — вывод интерактивной справки по командам.
    * `/exit` — безопасный выход и закрытие соединения.

## 🛠 Технологический стек

* **Язык:** Java 21+
* **Сеть:** Java Sockets (TCP/IP)
* **Многопоточность:** Threading, ExecutorService, Synchronized
* **Коллекции:** `ConcurrentHashMap` (для потокобезопасного управления сессиями клиентов)
* **Графика:** JavaFX

## 📦 Архитектура проекта

Проект логически разделен на два независимых модуля:

* `server` — бэкенд мессенджера. Управляет подключениями, проверяет уникальность никнеймов, обрабатывает команды, логирует историю в файл и рассылает сообщения.
* `client` — десктопное JavaFX-приложение для пользователей со встроенным асинхронным потоком прослушивания сервера.

## 🚀 Как запустить проект локально

### Шаг 1. Запуск Сервера
1. Откройте проект в вашей IDE (например, IntelliJ IDEA).
2. Запустите класс `server.ChatServer`.
3. В консоли появится сообщение: `Сервер запущен и ждет подключений...`. По умолчанию сервер занимает порт `8080`.

### Шаг 2. Запуск Клиента
1. Запустите класс `client.ChatClient`.
2. В появившихся диалоговых окнах введите:
    * **Адрес сервера:** `127.0.0.1` (если запускаете на одном ПК)
    * **Порт:** `8080`
    * **Ваш ник:** Уникальное имя для чата
3. Запустите еще несколько окон `ChatClient`, чтобы протестировать переписку между разными пользователями!

## 🌐 Как общаться с друзьями через интернет (Localtonet)

Если вы хотите протестировать мессенджер с друзьями из других сетей:
1. Зарегистрируйтесь на [localtonet.com](https://localtonet.com/) и запустите их клиент на вашем ПК.
2. Пробросьте **TCP** порт `8080`.
3. Передайте друзьям выданный адрес (например, `ru-1.localtonet.com`) и случайный внешний порт.
4. Ваши друзья при запуске `ChatClient` должны ввести эти данные вместо локального адреса.
